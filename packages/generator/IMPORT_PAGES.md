# 直接导入图片 / PDF 曲谱

生成器的「曲谱」区块支持直接导入真实谱面（图片或 PDF），按原样缩放显示，不会重新排版或绘制音符。与 `.zip` 曲谱包（见 [SCORE_PACK.md](./SCORE_PACK.md)）并存，两者可以混合使用。

## 导入规则

入口：`曲谱` → `导入图片/PDF`，文件选择器接受 `.png`、`.jpg`、`.jpeg`、`.webp`、`.pdf`，可多选。

- **图片**：所有图片按**选择顺序**视为**同一张曲谱的连续页面**。
- **PDF**：每个 PDF 文件各自视为**一张曲谱**，PDF 的每页渲染成一页。
- **混合选择**：可以一次同时选择图片和 PDF —— 图片合并成一张曲谱，每个 PDF 各自一张。
- 导入前会弹窗让用户确认/编辑曲谱标题，默认使用文件名（去掉扩展名）；点「跳过」则放弃该曲谱。
- 标题最多 24 个字符；曲谱 id 由标题自动生成（非 ASCII 标题回退为 `score`），冲突时追加 `-2`、`-3` 等后缀。
- 整个 addon 的曲谱总数仍受 **16 张**限制（模板已有 + 已导入 + 本次选择）。
- 单张曲谱最多 **64 页**；PDF 页数或图片张数超过上限时会给出中文错误并跳过该曲谱。
- 无法解码的图片、损坏的 PDF、不支持的扩展名会汇总到中文 `alert` 中；同一批里其它可导入的曲谱仍会成功加入列表。

## 生成的面板图：单页 A4 竖版

真实谱面通常是 A4 竖版。横版跨页会把整页缩得很小，因此面板图按**一页一张**生成：

- 每页生成一张 **1280×1810** 的竖版图（接近 A4 的 1:1.414 比例）；
- 页面按 contain 缩放并居中，纸张底色 `#FFFBEB`（RGB 255,251,235）；
- 输出路径：`textures/ui/piano_score/<id>/page_<n>.png`，`n` 是**原始页序号**（从 1 开始）；
- `PIANO_SCORES[].pages` 里放的就是这些单页图路径；
- 游戏内面板**一次只显示一页**，多页曲谱用「上一页 / 下一页」翻页。

例：一张 5 页的曲谱会生成 `page_1.png` 到 `page_5.png` 共 5 张。

## 压缩

- 灰阶谱面保留 **16 级灰度**，输出 4 位 PNG，兼顾抗锯齿和体积；
- 彩色页面退回 **32 色**自适应量化；
- 实际效果：《晴天》两页从约 1.14 MB 降到约 233 KB，谱架图从 216 KB 降到约 38 KB。

## 谱架纹理与 4 页限制

每个曲谱仍生成一张 **1024×1024** 的谱架纹理，规格与 `.zip` 曲谱包一致：

- 整张画布填充纸张底色 `#FFFBEB`；
- 底部绘制谱架木条/挡板的硬件 UV 条带（与 `tools/grand_score.py` 的 `paint_hardware` 一致）；
- 2×2 共 4 个竖版槽位，每个 **352×456**，按 contain 缩放居中：

  | 槽位 | 坐标 |
  | --- | --- |
  | page 0 | (0, 0) |
  | page 1 | (352, 0) |
  | page 2 | (0, 456) |
  | page 3 | (352, 456) |

- **谱架最多只显示 4 页**：真实曲谱超过 4 页时，谱架只放前 4 页，空槽位保留纸张底色；面板单页图仍包含全部页面。
- 输出路径：`textures/entity/piano_score/<id>.png`。

## PDF 渲染细节

- 依赖 `pdfjs-dist`，在浏览器内解析 PDF（文件不会上传服务器）。
- Vite 构建会把 pdf.js worker 打包成独立资源，通过 `?url` 引用：

  ```ts
  const pdfjs = await import("pdfjs-dist");
  const worker = await import("pdfjs-dist/build/pdf.worker.min.mjs?url");
  pdfjs.GlobalWorkerOptions.workerSrc = worker.default;
  ```

- 页面默认按 **2x** 渲染以保证文字清晰；单页像素超过约 1200 万时自动降低倍率，避免内存占用过大。
- 页面透明背景会先铺白纸，再转成 PNG。
- PDF 页数上限 64 页；pdf.js 与 worker 按需加载，不影响生成器首屏体积。
- 页面按需逐页渲染：每渲染完一页立即释放，不会把整本 PDF 的所有页面同时留在内存里。

## 与 .zip 曲谱包的区别

| 项目 | 直接导入图片/PDF | `.zip` 曲谱包 |
| --- | --- | --- |
| 图片分组 | 多张图片合并为一张曲谱 | 由 `score-pack.json` 显式声明 |
| 面板图 | 每页生成一张 1280×1810 竖版图 | 每张源图单独压成一张 1280×1810 |
| 压缩 | 16 级灰度 4 位 PNG（彩色页 32 色） | 16 级灰度 4 位 PNG（彩色页 32 色） |
| 谱架图 | 固定取前 4 页 | `standPages` 可选，最多取前 4 张 |
| 标题 | 弹窗确认，默认文件名 | `score-pack.json` 的 `title` |
| 页数上限 | 64 页 | 无硬性上限（受 16 张总数限制） |

导出时两种来源完全一致：都会重写 `scorePack.js`、`textures/ui/piano_score/`、`textures/entity/piano_score/`、RP 实体纹理表、render controller 与 BP 实体 `xypiano:score_variant` 范围。详见 [SCORE_PACK.md](./SCORE_PACK.md#导出后的-addon-文件)。
