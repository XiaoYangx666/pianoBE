- 600ms 释放下全库最大同时发声 **42**，出现在《周杰伦 - Secret》第 69.9 秒；全库有 **14** 首峰值超过引擎上限 32。

- 因此运行时按 28 的钢琴预算主动收掉“最不重要”的音（更轻、更接近 Note Off、谱面优先于手动）；导入时用同一模型预计算峰值并提示超限曲目。
- 28 预算下，31 首会触发回收：停掉 514 个实例、直接省略 344 个更轻的新音；所有实例句柄最终都归零。
